# 场景配方

每种场景都能在 `../assets/example/ExampleEpisode.tsx` 找到对应实现（括号里是该文件里的场景注释名）。时间都是相对场景开始的秒数，对齐配音里的关键词。

## 教程类的段落骨架

| 段落 | 口播功能 | 用哪种场景 |
|---|---|---|
| 开场 0–5s | “这是一期 X 零基础教程” | 组件 C |
| 定位 | 纠正误解：它不是 A，是 B | 误解 vs 其实 |
| 卖点 | 最大的区别 | 左右对比面板 |
| 能做什么 | 列 3–5 个场景 | 要点胶囊 |
| 预告 | 今天分三部分 | 要点胶囊 + 黄色总结贴纸 |
| 第一部分：怎么用 | 打开 → 登录 → 设置 | 步骤流 + 录屏（设置、额度） |
| 提醒 | 地区、额度、限制 | 提醒面板 |
| 第二部分：全部功能 | 逐个入口讲 | 设问板书 → 每个功能一段录屏 |
| 第三部分：实操 | 3–5 个真实任务 | 场景总览 → 每个任务“发需求 + 结果”录屏 |
| 没实测的场景 | 讲清能怎么用 | 示意图卡 + Note |
| 安全 | 批准卡、好习惯 | 步骤流 + 习惯行 |
| 结论 | 一句话对比 + 三招 | 双行大字 + 要点胶囊 |
| 结尾 | 评论区、下期见 | 机器人 + 气泡 + 贴纸 |

## 板书场景

### 误解 vs 其实（B）
左白色面板 `Pill“很多人以为”` + 白字大标题 + 小字例子；3 秒后粉色粗线斜着划掉；右面板 `Pill“其实它是”`（绿投影）+ 【紫色】大标题 + 一句解释。左右面板各转 ±2°。

### 左右对比面板（C）
顶部 `Title`；左面板写“不少 X”，配简笔图（`Laptop on`）；右面板写产品名，配 `Cloud`；结论句放黄色 `Tag` 贴在右下角。

### 要点胶囊（D、E、H、K、T）
`Title` 在上，`Chips` 在中（fontSize 56–66），每个胶囊在口播说到它时弹出；可选一条黄色总结 `Tag`，或底部一个机器人。

### 步骤流（F、Z1）
一行 `StepTag → ArrowPop → StepTag ...`，最多 3 步；最后一步用绿色底表示结果，关键中间步用黄色。

### 提醒面板（J）
居中大白面板：粉色投影 `Pill“提醒一句”` + 大字 + 一句安抚的话。

### 设问板书（L）
顶部 `Pill“第二部分 · 全部功能”`，中间问句大标题（【】高亮关键词），下方机器人 ring 眼。

### 示意图卡（W、Y）
左上 `Pill“场景 N · 名称”`，右上 `Note“示意图 · 本期未实测”`，`Title` + `Chips` + 简笔图（`Folder`、`Arrow`）+ 机器人 `SpeechBubble`。只讲“能怎么用”，不画产品界面。

### 习惯行（Z2）
三行 `HabitRow`：彩色数字圆 + 白色 `Tag`，逐行从左滑入。

### 结论与结尾（AA、AB）
两行大标题做对比（【A】帮你…… / 【B】帮你……），下方三招胶囊；结尾机器人 happy 眼居中，`BubbleAt` 气泡问“卡在哪一步”，黄色 `Tag“下期见！”`。

## 录屏场景

### 结构
```tsx
<Shots base={场景开始秒} shots={[
  [开始, 结束, s("c08", 源秒, 速度, [[0, x, y, w], [t, x, y, w]], [模糊区]), "场景 1 · 盯机票"],
]} />
<Callout from={相对秒} to={相对秒} x={1180} y={70} text="每 6 小时报一次价" />
```
`s()` 默认模糊旁聊列表；设置窗口这类无私人内容的段落传 `[]`，并写上 `sw, sh`。

### 镜头写法
- 关键帧 `[相对秒, x, y, w]` 是源视频像素，`h = w / 1.8`。
- 功能导览：先全景（`w = 源宽`）→ 2–3 秒后推到功能区（`w ≈ 1300–1750`）→ 结尾再推近重点（`w ≥ 900`）。
- 发需求：先对准输入框 `[500, 683, 1650]` 停到发送那一刻，再上移到消息气泡 `[450, 550, 1700]`。
- 结果：对准回复气泡或弹窗，0.5 秒内到位，后半段慢推。
- 网页成品：对准右侧网页面板，跟着滚动慢移。

### 强调贴纸节奏
每个录屏场景 1–3 条，一条对应一个口播重点，换句就换贴纸；颜色按“黄=重点、绿=结果、粉=坑”。
