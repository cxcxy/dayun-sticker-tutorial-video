# 风格基因：手绘贴纸风软件教程

样张见 `../assets/example/style-sheet.jpg`。组件与配色全部来自用户的 dy-video-kit 仓库（`src/lib/`），本文件只记录“怎么组合”，数值以组件库 `theme.ts` 为准；组件库改了配色，就跟着组件库走。

## 一句话

米白噪点纸上，用黄紫立体贴纸字讲观点，把真实录屏装进粗黑描边、硬投影的“贴纸屏幕卡”，镜头在卡里推近拉远，底部一条白底黑边字幕贯穿全片。

## 画幅与网格

- 横版 1920×1080，30fps。时长跟配音走，不为凑时长加空镜。
- 开场：组件 C（`OpeningC`，5 秒 / 150 帧）。第 0 帧就是完整标题，配音从第 0 帧开始，开场与第一句口播重叠。
- 录屏卡：`x=240, y=40, w=1440, h=800`，圆角 26，描边 7px 墨黑，硬投影 `12px 12px 0` 墨黑，卡内白底。
- 字幕：距底 44px，居中。卡底到字幕之间留约 150px 纸面，不让字幕压住录屏。
- 强调贴纸（Callout）默认挂在录屏卡右上角，`x≈1100–1250, y=70`，压住卡沿一半，像贴上去的标签。
- 卡片左上角放场景标签胶囊（`Pill`，30px，紫色硬投影），例如“功能 1 · 动态”“场景 2 · 挑东西”。

## 配色（theme.ts 的 C）

| 用途 | 色 |
|---|---|
| 纸底 | paper `#F4F1EA` + 每 4 帧换一次的噪点 |
| 字、描边、投影 | ink `#111111` |
| 标题主色 | yellow `#FFD84D` |
| 高亮词（【】内） | purple `#8B6CFF` |
| 正向、完成、“其实是” | green `#39FF88` |
| 提醒、风险、误解 | pink `#FF8FB1` |

强调贴纸的底色有语义：黄色是普通重点，绿色是结果或正向，粉色是坑、限制、提醒。一屏最多一个强调贴纸。

## 字体

- 标题和大字：站酷庆科黄油体（`FONT_TITLE`），用 `StickerText`，黄字黑描边硬投影，【】内的字变紫。
- 正文、字幕、标签：思源黑体 900（`FONT_BODY`）。
- 字号参考：板书大标题 104–130；面板主字 110–130；要点胶囊 54–66；字幕 50；强调贴纸 46；卡角标签 30。

## 组件分工

| 组件 | 用在哪 |
|---|---|
| `OpeningC` | 片头，内容来自 `episode.ts` 和 `channel.ts` |
| `PaperBackground` + 三颗 `PlacedSparkle` | 片头之后的全片底 |
| `Footage`（模板） | 所有真实录屏，带镜头关键帧和隐私模糊 |
| `Callout`（模板） | 录屏上的一句话重点 |
| `Title` / `Chips` / `Panel` / `Tag` | 板书场景：标题、编号要点、白色面板、贴纸标签 |
| `PlacedRobot` | 板书场景的吉祥物，提问时 ring 眼，结论时 happy 眼 |
| `SpeechBubble` | 机器人说的话、需要“确认/提醒”的口语句 |
| `Laptop` / `Cloud` / `Folder` / `Arrow`（模板） | 简笔示意图，CSS 画，不用 emoji |
| `Note`（模板） | 右上角小字“示意图 · 本期未实测” |

## 动效

- 所有弹出都用 `softSpring`，力度统一 `K = 0.56`（与组件 C 一致），阻尼 9–14。
- 元素出现时间对齐配音里对应词的时间，不是平均分布。
- 录屏卡进入：0.94 → 1 轻弹；同一段落内切镜头不再弹。
- 镜头：关键帧之间 `Easing.inOut(cubic)`；一个镜头最多 3–4 个关键帧；推近不小于源宽 900px（避免放大发虚）。
- 机器人：上下浮动 `sin(frame/7)*6`，每 3 秒眨眼一次，提手摆动。

## 不做的事

- 不用 emoji（无头浏览器可能缺字体）、不用渐变、不用阴影模糊，阴影一律硬投影。
- 不伪造产品界面。没录到的功能用简笔示意图，并挂 `Note`。
- 片尾不加关注引导、不加固定人设句，除非当期明确要求。
- 不改 `episode.ts`、`channel.ts` 里用户写好的标题、钩子、要点和频道名；发现和口播不符时报告，由用户决定。
